# Web Portfolio

Website portofolio pribadi — HTML, CSS, JavaScript (Bootstrap 5).

## Struktur Workspace

```
├── assets/           # Gambar (screenshot project, foto profile, dll)
├── docs/
│   └── projects/     # PRD & dokumentasi project
│       └── _template.md
├── index.html        # Halaman utama (semua konten)
├── main.js           # Interaktivitas (loader, animasi, filter)
├── style.css         # Semua styling
└── README.md
```

## Cara Menambah Project Baru

1. Buat file PRD di `docs/projects/` (copy dari `_template.md`)
2. Taruh screenshot di `assets/`
3. Edit `index.html` — tambah project card di `<div id="project-grid">` (baris ~474)
4. Atau minta saya yang kerjakan 😉

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Bootstrap 5.3
